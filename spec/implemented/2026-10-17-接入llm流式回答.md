# 接入 LLM 流式回答

## 目标 / 背景

检索链路（改写、混合检索、精排）已验证通过。本步把命中的知识块组装成运行期 Prompt，流式调用对话模型生成客服回复，取代原占位文本。运行期规则复用 `knowledge_base/config.py` 的 `ANSWER_SYSTEM_PROMPT`（PRD：只依据资料/不确定不编造/孕妇婴幼儿宠物过敏谨慎提示/不承诺价格库存发货退款/不闲聊/3 句内口语化）。

## 改动范围

- `website/backend/chat.py`：
  - 新增 `_build_messages(question, results)`：把检索块拼成 `【标题】\n正文` 上下文，system 用 `config.ANSWER_SYSTEM_PROMPT`。
  - 新增 `_stream_llm(messages)`：httpx 直连 `{AGICTO_BASE_URL}/chat/completions`，`stream=true`，只取 `delta.content`（忽略 `reasoning_content`），逐段 yield。
  - `_stream` 在 sources 之后流式下发 `event: content`（`data: {"text": "..."}`）；LLM 异常 → `event: error`（中文可读提示）；无命中 → `event: error`；最后 `event: done`。
  - 删除占位回复与临时观测 print。
- `website/backend/requirements.txt`：新增 `httpx>=0.27`（chat.py 直接依赖）。
- 未改动 `knowledge_base/` 下任何文件。

## 验收标准

- `{"message":"蜡烛烧出洞怎么办"}` → retrieval → sources → 多段 content（隧道效应补救答案）→ done，流式逐段输出。
- `{"message":"讲个笑话给我听"}` → content 拒绝闲聊并引导回香薰话题，符合 PRD。
- API Key 从 `.env` 经 config 读取，未硬编码。
