# SSE 流式通路（后端骨架 + 假数据流）

## 目标 / 背景

项目第一步：先跑通 FastAPI + SSE 流式输出通路，为后续接入真实 RAG 与 LLM 打底。此阶段不接真实检索与生成，用固定中文假回答逐字 yield 验证 SSE 通路。

## 改动范围

- 新建 `website/backend/main.py`：FastAPI 入口 + CORS（允许 `http://localhost:8000` 与 `file://`（即 `Origin: null`））。
- 新建 `website/backend/chat.py`：`POST /api/chat/stream`，返回 `StreamingResponse`（`media_type="text/event-stream"`），用生成器按 `retrieval → sources → content(逐字, 每字 0.05s) → done` 四类事件输出假数据。
- 新建 `website/backend/requirements.txt`：fastapi、uvicorn[standard]、python-dotenv。
- 新建 `website/backend/.env.example`：占位符，无真实密钥。
- 新建 `website/backend/.venv` 并安装依赖。
- 未改动 `knowledge_base/`、未改动前端文件。

## 验收标准

- `curl` 接口能依次收到 `event: retrieval` / `event: sources` / `event: content`（逐字）/ `event: done`。
- CORS 对 `http://localhost:8000` 和 `null`（file://）两个来源均返回正确的 `access-control-allow-origin`。
