# 建立 RAG 知识库（混合检索 + 精排 + 生成）

## 目标 / 背景

把产品使用说明文档建成可检索的知识库，支撑香薰客服 RAG 问答。数据源 `信息资料/香薰蜡烛产品使用说明.md`，检索方式为 FAISS 向量语义 + BM25 关键词混合 → rerank 精排。详见 `知识库搭建技术文档.md`。

## 改动范围

- 新建 `knowledge_base/` 各模块：`config`（配置）、`chunker`（切块 + 关键词）、`embedder`（embedding）、`keyword_index`（BM25）、`store`（持久化）、`retriever`（混合检索）、`rewriter`（query 改写）、`reranker`（精排）、`websearch`（联网兜底）、`answerer`（回复生成）、`recommender`（香气推荐）。
- 新建 `build_kb.py`（构建入口：解析 → 切块 → embedding → 落盘）、`search.py`（问答入口）。
- 新建 `推荐数据/scents.json`（15 款香型结构化数据）。
- 生成 `kb_data/`：`index.faiss`（FAISS `IndexFlatIP`）、`chunks.json`（68 块）、`meta.json`。
- 根目录 `.env` 配置 AGICTO（API Key 走环境变量）。

## 关键实现（要点）

- 切块：按 Markdown 标题切分，`###` 为一块、`##` 为 category；表格逐行转自然语言；每块 200–500 字。
- 关键词：`jieba.analyse.extract_tags` + 人工规则词表（香型名 / 专业术语），自定义词典防切碎。
- Embedding：`tongyi-embedding-vision-flash` 走 DashScope 原生协议（`output.embeddings[]`），httpx 直连、L2 归一化。
- 混合融合：`final = 向量分 + 0.25 × BM25 分`（加法增强，关键词只加分不惩罚）。
- 检索链路：query 改写（deepseek-flash 3 条）→ 4 路打分 → RRF 融合 → rerank（gte-rerank-v2）精排 → top-k；低分自动联网兜底；回复由 deepseek-v4-pro 生成；星座/MBTI/场景走香气推荐前置分流。
- 2026-10-14 香型改名：波西玫瑰/牡丹/睡莲 → 青玫/墨绯/眠莲，`--force` 重建（仍 68 块）。

## 验收标准

- 68 块 / 768 维，构建无异常。
- 技术文档 §7 验证：隧道效应、礼盒价格、保质期、宠物安全、烛芯 5mm、黑烟处理等查询 top-1 命中正确，开启 rerank 后 top-1 稳定。
