# 修复改写模块空 query 污染

## 目标 / 背景

用户反馈：改写模块仍会返回「请提供需要改写的用户提问内容」，模型在反问而非改写。诊断：当用户消息为空/纯空白时，`rewrite_queries` 仍把空消息发给模型，模型反问「请提供提问内容」，而 `_parse_queries` 又把这句话当成一条「改写 query」传回，污染检索结果。

## 改动范围

- `knowledge_base/rewriter.py`：`rewrite_queries` 顶部加空/纯空白 query 守卫，直接返回 `[]`（回退为仅用原 query），不再把空消息发给模型。
- `website/backend/chat.py`：接口对空/纯空白 `message` 校验，返回 HTTP 422（`message 不能为空`）。
- 本次改动 `knowledge_base/rewriter.py` 为修复该 bug 所需，用户已明确要求。

## 验收标准

- `rewrite_queries("")`、`rewrite_queries("   ")` 均返回 `[]`。
- 真实 query 仍正常返回 3 条改写。
- 接口空 message → HTTP 422；正常 message → HTTP 200 且 `rewritten_queries` 无「请提供」等模型反问。
