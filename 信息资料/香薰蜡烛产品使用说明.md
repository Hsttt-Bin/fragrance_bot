# 香薰类、蜡烛类产品专业使用说明

---

## 一、香薰蜡烛使用说明

本店香薰蜡烛按形态分为**造型蜡烛**和**容器蜡烛**两类，使用方式不同：造型蜡烛可先摆放自然扩香，容器蜡烛以点燃扩香为主。

### 1. 造型蜡烛 · 自然扩香与点燃注意事项

- 造型蜡烛可摆放在**客厅、卧室、书房**等空间，无需点燃即可自然扩香
- 自然扩香无明火、无烟，适合长时间稳定散香
- 如需更浓郁香气，可转为点燃使用

**点燃注意事项**：
- 点燃前将烛芯修剪至 5mm-8mm
- 首次请持续燃烧至蜡烛边缘，形成完整蜡池
- 保持烛芯中立，每隔 2 小时左右熄灭并修剪烛芯
- 使用灭烛勾将烛芯按入蜡油中熄灭，再勾出以便下次使用
- 请勿将蜡烛置于浅色表面，建议使用垫子承接蜡液
- 若有蜡油流淌，请熄灭待凝固后清理蜡油，再点燃
- 务必不要将蜡烛处于无人看管状态

### 2. 使用前准备

**修剪烛芯**
- 每次点燃前，使用专用烛芯剪将烛芯修剪至 5毫米（约1/4英寸）
- 过长的烛芯会导致火焰过高、产生黑烟并熏黑杯壁
- 过短的烛芯容易被蜡液淹没熄灭
- 修剪后需清除落在蜡面上的碎屑，避免杂质影响燃烧
- 本店蜡烛使用无铅纯棉芯，燃烧安全（详见「成分安全」章节）

**温度适应**
- 冬季户外购买或快递送达的蜡烛，需在室温下静置 1-2天 后再点燃
- 冷蜡直接点燃会导致燃烧不均、扩香效果差
- 存放在温度适中的房间，远离暖气片或冰冷车库

### 3. 首次燃烧（最关键步骤）

蜡有"热记忆"——第一次燃烧决定了整支蜡烛的后续燃烧轨迹：

- 首次点燃必须持续 2-4小时，直到蜡液完全融化至杯壁边缘，形成平整蜡池
- 蜡烛直径5cm约需1小时，直径10cm约需2-3小时
- 若中途熄灭，会形成"隧道效应"（tunneling）——中间烧出深坑，四周蜡壁无法融化，白白浪费大半支蜡烛
- 绝对不要在蜡池到达杯壁前熄灭蜡烛
- 首次点燃建议至少持续 2 小时以上，烧出完整蜡池再熄灭，避免隧道效应

### 4. 日常使用规范

| 项目 | 规范 |
|---|---|
| 单次燃烧时长 | 2-4小时，不超过4小时 |
| 冷却时间 | 熄灭后至少等待2小时再重新点燃 |
| 烛芯长度 | 每次点燃前保持5mm |
| 停用标准 | 底部剩余约1cm蜡液时停止使用 |
| 摆放距离 | 远离窗帘、纸张等易燃物至少30cm（10cm最低） |
| 环境要求 | 阴凉、无直射风的稳定环境 |

**单次不超过4小时的原因**：燃烧过久会导致蜡液过热，香精中的中调和后调挥发过快，香气提前耗尽；烛芯尖端会积碳形成"蘑菇头"，导致火焰不稳。

### 5. 正确熄灭方法

禁止用嘴吹灭——会产生大量黑烟、蜡油飞溅覆盖烛芯、焦味残留室内。

推荐方式（二选一）：

1. **灭烛罩法**：将金属/玻璃罩直接罩住火焰，隔绝氧气自然熄灭，全程无烟无味，同时保留室内已释放的香气
2. **灭烛钩法**：用灭烛钩将烛芯按入蜡液中，火焰熄灭后立即将烛芯扶正居中

熄灭后操作：
- 不要触碰或移动蜡烛，直到完全冷却
- 趁蜡液尚软时将烛芯居中
- 蜡完全凝固后才盖回盖子存放

### 6. 常见问题处理

| 问题 | 原因 | 解决方案 |
|---|---|---|
| 隧道效应（中间凹陷） | 首次燃烧时间不足 | 下次延长燃烧时间；或用锡纸包裹杯口补烧；严重时小心挖除边缘多余蜡 |
| 黑烟/烟灰 | 烛芯过长 | 熄灭冷却后修剪至5mm再点燃 |
| 点不着 | 棉芯受潮或过长 | 剪短擦干后重试 |
| 火焰摇晃倾斜 | 处于风口位置 | 移至无风位置；偶尔旋转蜡烛保持均匀 |
| 挂壁不均 | 气流导致单侧燃烧 | 避开空调出风口、开窗处 |
| 蜡面白霜/起霜 | 大豆蜡天然特性 | 不影响使用，是纯天然蜡的正常表现 |
| 蜡与杯壁分离 | 温差变化所致 | 仅影响外观，不影响燃烧性能 |
| 香味变淡 | 香精随时间自然挥发 | 属正常现象，建议保质期内使用并避光存放 |

### 7. 扩香优化与空间匹配

- 小蜡烛（140g）适合卫生间、书房
- 中蜡烛（200g）适合卧室、厨房
- 大蜡烛适合客厅、开放式空间
- 放在空间中央比角落扩香更好，台面/壁炉台等高处优于地面
- 关门可帮助香气集中，开放空间可能需要多支蜡烛

### 8. 存储与保养

- 盖好盖子存放，防灰尘落入蜡面（灰尘会成为多余燃料，影响火焰洁净度）
- 存放在阴凉避光处，避光避热，避免阳光直射（大豆蜡遇热会软化）
- 使用后用软布擦拭杯壁灰尘
- 保质期18个月，建议在保质期内使用

### 9. 安全检查清单

**每次点燃前检查：**
- 烛芯已修剪至5mm
- 容器干净无碎屑
- 摆放在稳定耐热表面
- 远离易燃物30cm以上
- 远离儿童和宠物
- 不在风口位置

**燃烧中要求：**
- 不离人
- 视线范围内
- 不超过4小时
- 火焰稳定直立（不过度闪烁）

## 四、成分安全

### 1. 蜡基成分

- 造型蜡烛：蜂蜡和棕榈蜡
- 容器蜡烛：进口大豆蜡、少量椰子蜡和蜂蜡
- 均不含石蜡，比石蜡更环保、燃烧更清洁

### 2. 香精来源

采用 IFRA 国际认证香精，部分为天然精油调配，非 100% 纯精油；系香氛级标准，而非食品级标准。

### 3. 棉芯材质

使用无铅纯棉芯，燃烧安全。

### 4. 燃烧表现

大豆蜡燃烧无黑烟、无异味；若冒黑烟多为棉芯过长，需修剪。

### 5. 检测报告

通过 SGS 检测，无甲醛、无有害 VOCs 超标，燃烧安全；具体证书可转人工提供。

### 6. 孕妇 / 备孕 / 哺乳期

孕期建议谨慎使用，因香精会挥发，建议遵医嘱或避开高香型；备孕、哺乳期同理。

### 7. 婴幼儿

3 岁以下婴幼儿房间不建议直接点燃使用。

### 8. 宠物安全

- 猫科对部分精油较敏感，养猫家庭建议保持通风，避免柑橘类等刺激性香型
- 狗狗相对耐受，但同样建议保持通风、避免长时间密闭使用

### 9. 过敏与呼吸道敏感人群

- 呼吸道敏感或过敏体质者建议先少量短时试用，无不适再正常使用
- 呼吸道疾病患者（含哮喘）不建议使用，或仅在通风良好环境下少量短时
- 如闻到气味后有咳嗽等不适，立即停止使用并保持通风

### 10. 使用安全警示

- 蜡烛仅作点燃香薰使用，不可涂抹皮肤、不可食用
- 蜡烛无空气净化、医疗等功效，不能替代治疗，请勿夸大功效
